# 我的错题本：实现与接口

用户授权在学习书架下增加错题本，自动记录错题并可定位书中知识。本轮沿用当前技术栈及书房视觉，无新增依赖或模型费用。

## 参考与取舍

- Quizlet 官方「Studying most-missed terms with stars」：借鉴将需要重点复习的内容集中筛选，不复制星标逻辑或视觉资产。https://help.quizlet.com/hc/en-us/articles/360031172312-Studying-most-missed-terms-with-stars
- 有道智云 AI+教育：借鉴自动整理错题与知识点归纳。https://ai.youdao.com/ai-education.s
- 悦读以书籍和故事为载体，因此以书/章/原文摘录为复习线索；自动收录而非手动收藏。暂不新增题目生成、间隔复习算法或独立评分规则。

## 数据与迁移

新增 mistakes 表，不改已有表字段。逐题保存作答时在同一事务写入错误题快照；整卷提交也归档错题。启动时幂等回填仍存在的 quiz_attempts，与现在的章节题目配对，只接受有效且错误的选择。换题仅清当前 quiz_attempts，错题快照不受影响。

每条快照存 question/options/choice/answer/type/explanation/knowledge/source_paragraph/source_excerpt/chapter_title；另存 id/book_id/chapter_no/created_at/mastered。question_key 为题干、选项、正确答案、原文摘录的 SHA256，书/章内唯一。重复收录不会重置手动掌握状态。不宣称能恢复已被旧代码删除的作答。

权限通过 mistakes JOIN books 并限定当前 session user_id，GET/PATCH 均强制后端鉴权；不接受客户端 user_id。

## 接口契约

| 请求 | 输入 | 成功响应 | 失败 |
|---|---|---|---|
| GET /api/mistakes | 无 | {mistakes: Mistake[]}，按收录时间倒序 | 401 |
| GET /api/mistakes/{id} | 错题整数 ID | {mistake: Mistake} | 401/404 |
| PATCH /api/mistakes/{id} | {mastered: boolean}，严格布尔 | {id, mastered} | 401/404/422 |

Mistake 为上述快照加 book_title/topic/mastered/created_at/id/book_id/chapter_no。不存在与不属于本人均返回 404，错误统一 {error:{code,message}}。PATCH 幂等；前端 15 秒超时，失败提示且不更新假状态，可手动重试。

## 页面与定位

/mistakes：待巩固/已掌握/全部，书筛选、文本搜索、答案讲解折叠、原文摘录、可逆掌握标记，加载/空/搜索空/失败状态。

链接 /book/{book_id}?chapter={chapter_no}&mistake={id}：先验证错题所属书，再加载指定章节，保持既有后端阅读权限。按快照全文匹配段落，高亮并滚动；找不到时明确说明，不跳到其他知识。回顾期间跳过阅读位置存储、自动预生成和自动首章生成，返回错题本入口保持可见。
