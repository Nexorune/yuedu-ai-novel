# 落地页杂志风视觉改造

## 本轮适配与范围

产品经理于 2026-10-22 选定方案 A 的截图，并授权直接实现。目标为米白纸感、宋体大标题、陶土橙主按钮、自然光书页与答题浮卡，阅读示例先于三步说明展示。仅调整首页；保持全部原有说明、示例正文、题目及四个 FAQ。FAQ 使用原生 details/summary 展开，题目仍为静态展示。

沿用既有 Next.js / React / TypeScript、账号 hook、共享导航及协议页。首页采用 CSS Modules 隔离样式，不新增依赖；访客使用全宽页面，登录后保留书房侧栏。开始学习仍按账号状态跳转登录或 /create。账号读取失败时沿用访客展示。

## 素材与实现

- `frontend/app/page.tsx`：首页布局、静态示例及 FAQ。
- `frontend/app/landing.module.css`：局部样式与按容器宽度重排的布局。
- `frontend/public/images/landing/reading-room.png`：自然光室内背景。
- `frontend/public/images/landing/river-reading.png`：书页河畔插画。
- 图片使用 next/image 提供尺寸适配和优化，首屏预加载，下面的插画延迟加载。页面文案均为 HTML 文本，背景图中没有文字。
