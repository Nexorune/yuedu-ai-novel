# 前端技术适配声明

> 2026-10-22 首页视觉增量：产品经理选定米白/陶土橙杂志风方案 A，使用独立 CSS Modules 和本地生成的两张装饰图片实现；沿用原账号、路由和业务组件，无新依赖。范围及验收见《落地页杂志风-20261022.md》。

## 1. 项目判断
- 产品类型：生成式内容产品（网文阅读 × 学习关卡）
- 主要用户：18–35 岁，爱看网文又想碎片化学习的人
- 主要终端：桌面 Web + 移动 Web（手机阅读是主场景）
- 新项目或已有项目：已有项目（后端 FastAPI + 最小 HTML 已跑通），前端为新建正式版
- 本阶段业务目标：把"最小 HTML"升级为正式网页版，完整跑通「新建书 → 逐章生成 → 读 → 答 5 题对 3 解锁 → 完结 → 结局画廊」

## 2. 输入资料
- PRD：已读取 ✓
- 后端手册：已读取 ✓
- 接口文档：已有 API 契约（web.py 已定义，前缀 /api）
- 设计稿：无；产品经理已选择中性阅读风（浅暖底色、清晰排版、低干扰卡片）
- 现有代码：有（backend/ + 最小 HTML）

## 3. 技术选择
- 框架与版本：Next.js（App Router，稳定版）+ React 19 + TypeScript strict；Node 24 / npm
- 样式与组件策略：Tailwind CSS 4 + 语义化 CSS 变量；Lucide 图标；原生 HTML + 轻量自建组件（不引重型组件库）
- 数据请求与状态策略：集中式 API 层（`lib/api`）+ 手写 fetch + 轮询；后端是任务状态唯一事实来源
- 流式通信策略：轮询（后端已实现「提交任务 + 轮询状态」，MVP 够用，不引 SSE）
- 表单方案：React 受控组件 + 前端校验（新建书表单字段少，不引 React Hook Form）
- 测试方案：ESLint + TypeScript 类型检查 + 生产构建 + Vitest；Playwright 覆盖核心闭环（如环境允许）
- 部署环境：本地预览（frontend 3000 端口 + 代理 /api → 后端 8787）；上线时 Next.js standalone 独立部署

## 4. Agent 状态
- 后端状态 → 前端统一映射：`pending→submitting`、`running→running`、`done→succeeded`、`error→failed`
- 等待用户确认方式：无（产品无中间确认点）
- 取消/重试/断线恢复：刷新后按 book_id / task_id 重新拉取后端真实状态；生成中禁止重复提交（按钮 disabled）
- 任务 ID 和恢复入口：book 列表（书 ID）+ 轮询 task_id；进度文案（已等待 N 秒）已在后端提供

## 5. 页面与产物
- 核心页面：首页（书列表 + 新建书）、阅读页（正文 + 答题）、结局画廊页
- 核心业务闭环：新建书 → 等大纲 → 读下一章（生成中显示进度）→ 答 5 题 → 解锁/换题 → 完结 → 画廊
- 产物类型：文本章节（正文 + 题目），纯文本渲染
- 响应式目标：390 / 768 / 1280 三档，手机阅读优先

## 6. 偏离本手册的地方
| 偏离项 | 原因 | 影响 |
| --- | --- | --- |
| 用轮询而非 SSE | 后端已实现「提交任务+轮询」，MVP 足够 | 无 |
| 不引 TanStack Query / Zustand | 单用户本地、页面少，手写 fetch 足够 | 无 |
| API 前缀沿用 /api（非 /api/v1） | 后端已建成，避免破坏现有契约 | 无 |
| 暂不接登录/鉴权 | PRD 定为 MVP 本地档案 | 无 |
