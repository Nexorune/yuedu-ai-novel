# 测试登录记忆与落地页适配

## 范围

根据产品经理要求，保留本地登录表单输入，点击手机号自动填写测试码；随后修正选定落地页风格在窄窗口的书页边缘裁切。随后按产品经理补充要求取消成年门槛，仅保留协议确认；创作流程和账号数据隔离保持原逻辑。

## 登录

- 浏览器 `yuedu-login-memory-v1` 仅保存 phone、agreed。首次手动输入/勾选后持久化；换手机号取消旧确认，清除记录会删除保存内容。
- 不保存验证码或会话凭证。点击完整手机号、或输入到完整号码时，请求后端演示码；仍需点击登录。
- `DEMO_LOGIN_AUTOFILL` 默认 false，本机忽略文件中已设 true。关闭后不自动请求、不恢复勾选，手机号仍保留。公开上线需另行完成真实短信等 PRD 项目。
- 自动请求有取消/序号保护；切换手机号、清除记录、手动改码后，过期响应不能覆盖当前表单。禁用存储或损坏记录不阻塞手动登录。

## 接口

- GET `/api/auth/me`：响应增加可选布尔值 `demo_autofill`，既有 user 不变。
- POST `/api/auth/code`：请求 `{phone, demo_autofill?: boolean}`；未开启返回原有 sent/cooldown，开启额外返回 demo_code，响应禁止缓存。
- 关闭时拒绝 `demo_autofill=true`，返回 HTTP 403，`{"error":{"code":"DEMO_DISABLED","message":"测试自动填写已关闭，请手动获取验证码"}}`。防止旧页面自动请求将来误触发真实短信。其他校验沿用统一错误结构。

## 适配

实际内置浏览器窗口宽 456px；页面整体宽度没有溢出，但固定高度书页配合旋转和父级裁剪，导致视觉上被撑出屏幕，正文及浮卡互相挤压。

改为书页随内容撑高、答题卡参与正常排版并只搭在书页底部留白处；小屏缩小纸张旋转角度并预留两侧空间。标题允许必要换行，双栏使用可收缩的网格轨道，窄屏保持单栏。首页是可纵向滚动的长页面，不压缩为一屏。

## 验证边界

登录浏览器验证使用 localhost 的独立存储空间和合成测试手机号，未提交登录、未创建用户；原有该来源记录测试后恢复。验证码截图已遮挡。真实模型未调用；此前自动写第一章的真实模型验证仍待验。

## 年龄门槛取消（产品经理追加要求）

- 登录仅保留用户协议/隐私政策的一个勾选框，后端也不再校验成年确认。
- 登录与创作请求不再发送成年字段；旧客户端多传该字段仍兼容接受，不迁移或删除历史用户数据。
- 已存手机号与协议选项沿用旧存储键恢复，旧 adult 字段忽略，下次保存自动移除。
- 同步登录页脚、现行协议文案、生成系统提示词和现行 PRD；旧版文档和历史验收记录保留。内容审核继续生效。
- 历史 CLI 取消年龄询问；旧 require_adult 函数保留为不询问、不拦截的兼容入口，对应测试按新需求更新。
- 生成提示词文案已调整，真实模型效果待验，本次不调用模型。
