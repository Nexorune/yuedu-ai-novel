# 错题本按书整理

## 范围

将原平铺错题卡片改为书本目录、书内章节列表两级。沿用既有 SQLite 快照、接口、账号隔离和原文定位规则。本轮不改数据结构或收录逻辑。

## 交互与实现

- `/mistakes`：按最近收录顺序归集到书本，显示书名、主题、章节数及掌握分类数量；每页 12 本。
- `/mistakes?book=ID`：仅展示该书题目，按章节排列，每页 20 道；可按章节、掌握状态、关键词筛选。
- 题目折叠时只显示题干、知识摘要与类型；同时最多展开一题，展开后才渲染选项、正确答案、讲解与原文。原文摘录可进一步展开。
- 筛选和换页重置展开状态；浏览器前后退清除临时章节与关键词条件，地址刷新仍恢复书本。
- 阅读页在错题回看模式下，返回链接保留所属书籍 ID。
- 分页为前端展示分页，当前接口仍一次读取本人全部错题。后端聚合与分页为数据规模增长后的改进点。
