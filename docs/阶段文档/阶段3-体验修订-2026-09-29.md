# 阶段 3 体验修订（2026-09-29）

## 产品反馈与实现

1. 每本书应有书名。新书在大纲生成时由模型命名，书架和阅读页展示书名及学习主题；已有 8 本其他主题书已补名。
2. 本章答题区出现时，若计划还有下一章，后台立即启动下一章生成。任务复用，刷新后可恢复；本章答题通过前，下一章内容仍被后端拒绝访问。用户通过后点「读下一章」，已生成则直接阅读。提前生成可能让“就此完结”前多产生一次模型费用；未读草稿会被结局章覆盖，不改变已读章节。
3. 题目只能巩固学习主题。生成提示词明确排除剧情题；本地拦截明显剧情问法和小说人物名，再经模型逐题复审。不合格时保留已审核正文，只依据知识点独立重出题，减少等待与重复正文生成费用。换题也走同一审核。
4. 书籍 #8、#9 的学习主题均为“性知识”，已从书架隐藏，数据库原文和进度保留。是否永久删除待产品经理确认。
