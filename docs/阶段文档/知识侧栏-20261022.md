# 章节知识侧栏调整

按用户反馈将知识清单从阅读正文末尾迁入既有左侧目录抽屉。阅读顶栏新增带文字的知识按钮，直接选择知识视图；目录按钮选择章节视图，抽屉内部可切换。

复用 ChapterKnowledge 的本章与全书清单、懒加载搜索、失败重试和原章链接，增加紧凑排版及跳转关闭回调。后台接口与可读章节权限不变。章末不再渲染知识清单，闯关结果反馈中的知识复习保留。

抽屉头部不收缩、内容独立滚动，手机保留外侧遮罩，沿用阅读主题；useDialog 的焦点范围包含原生 summary，以支持全书知识章节展开。
