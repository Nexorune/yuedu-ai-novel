# 学习书架与层级修正

## 已确认范围与适配

产品经理指出登录后不应出现落地页，进入后应看学习和学习进度；工作区需要更接近最初 Readowl 参考的书架质感，并适应屏幕。基于现有 Next.js、CSS Modules 和书单接口实现，不新增依赖或修改后端，不迁移数据。

## 页面与导航

- `/` 始终展示独立落地页；已登录时提供「进入学习书架」，不再自动跳转。
- 登录默认去 `/library`；仍保留安全的 next 地址用于回到原本受保护页面。
- `/library` 是登录后的学习首页：最近阅读、正在学习、已经读完、真实进度、搜索及展开全部。
- `/create` 只保留原有新建表单和全部参数/错误状态。旧 `/create#books` 无论直接打开还是同页锚点变更都兼容跳转书架。
- 侧栏「学习书架」、阅读返回、结局画廊和个人中心的学习记录指向 `/library`；品牌 Logo 按最新反馈返回 `/`，外部落地页不带工作区侧栏。

## 视觉和适配

主外框最大 1120px，桌面和手机均自然整页滚动，不限制主面板高度；桌面侧栏随窗口高度适配、账号留在底部，矮窗口隐藏装饰书；窄屏切换顶栏。书架使用实体封面、书脊、页边、连续搁板及投影；章节进度与题材仍是真实数据。根据内容容器宽度切换 6/4/3/2 列；新建表单也按实际内容宽度重排，保留更多设置。

## 状态和接口

使用现有 `/api/auth/me` 和 `/api/books`；加载、空数据、错误及重新加载分开显示。最近阅读仅用于排序，书籍和学习进度来自后端；查不到当前账号的本地最近书号时不展示其他账号内容。搜索没有匹配时可清除，展开全部可访问全部历史书籍。

## 验证范围

真实账号只读核对书单/进度、搜索、导航和刷新恢复，不创建新任务、不触发模型调用。自动化覆盖匿名落地页、登录后可访问外部落地页、导航层级、书架分组与进度、空状态和错误重试；浏览器覆盖多尺寸以及旧锚点链接。历史真实模型验收仍待验，本轮不替代。

## 同日追加反馈

导航改为新建在上、书架在下；删除新建页眉题。新增共享账号菜单（鼠标悬停、触屏点击、键盘开关、外部点击关闭；真实退出接口及失败重试）。六组本地矢量插画封面替代统一羽毛图案，并加强书脊、纸页、深浅配色。账号在侧栏底部的决定覆盖中途上移尝试。无依赖、后端或数据结构变化。最新证据见 `docs/evidence/阶段3/账号菜单与书架细节-20261022/`。

首页和学习区使用 `--page-content-max: 1120px`、`--page-gutter: clamp(20px, 6vw, 96px)`；首页页头和各内容容器统一对齐，删除原先不一致的分段宽度覆盖。背景不收窄。见左右留白证据包。
