# 章节知识清单

## 目标与适配

用户希望除做题外，能够集中查看小说涉及的知识。沿用 Next.js、CSS Modules、FastAPI 和既有 SQLite 知识数据；不增加模型请求、数据库迁移或费用。

## 页面

每个可读章节正文后增加独立知识区，闯关前后及结局均可查看。顶部灯泡跳转入口。核心知识在前、拓展知识在后，完整展示已有说明；通关区原重复知识卡片移至统一位置，QuizMode 内的通关反馈保留。

本书目录按章节折叠，支持关键词搜索、自动展开匹配章节、跳回原章。仅访问目录时请求汇总，失败可重试，不影响本章清单。组件随章节切换重新初始化，异步请求取消后不覆盖新数据。

## 接口

- `GET /api/books/{book_id}/chapters/{chapter_no}`：原 `knowledge_points: [{role,point}]` 在可读章节未通关时也返回；其他字段不变，题目仍只返回公开字段，不带正确答案或解析。
- `GET /api/books/{book_id}/knowledge`：无请求体，返回 `{chapters:[{chapter_no,title,is_ending,knowledge_points:[{role,point}]}]}`。章节号排序；无章节返回空数组。
- 账号鉴权及书籍归属由现有后端中间件控制。当前阅读进度 + 1 以内章节可见；已完结书的可读结局一并列出；预生成的更后章节不返回标题或知识。
- 未登录 401、他人/不存在书籍 404，错误格式保持 `{error:{code,message}}`。

## 验证与边界

80/80 后端、44/44 前端、类型/Lint/生产构建通过。新增测试覆盖未通关知识可读但答案不泄露、目录可读范围、已收集结局、账号隔离、空数据、重开数据库、核心排序、搜索、目录请求失败重试与章节链接。

展示范围是已生成并保存的知识点清单，不宣称自动穷尽正文中所有隐含概念。未生成或尚未解锁部分随阅读进度加入，不提前展示完整故事。证据：`docs/evidence/阶段3/章节知识清单-20261022/验收说明.md`。
