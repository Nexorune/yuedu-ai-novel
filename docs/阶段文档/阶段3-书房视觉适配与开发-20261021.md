# 书房视觉适配与开发

## 授权与当前基线

产品经理于 2026-10-21 明确要求按提供的 Readowl 参考截图改造视觉，内容不变，并先读取后来修改的版本。已读取 10 月 18 日的落地页、独立创作页、登录、个人中心、协议、阅读、闯关及结局画廊相关实现，以当前代码为唯一实施基线。

## 前端适配声明

沿用 Next.js 16.3.6、React、TypeScript、现有 CSS 和 Lucide 图标，不添加依赖，不改 API、模型调用、账号隔离、数据结构、文案与业务状态流转。采用灰蓝外背景、暖白外框、奶油色内嵌区域、棕色字色、细线图标、柔和投影、实体书封与浅木书架。保留悦读品牌及书籍原有文字，不引入参考图中的商店、新闻、搜索等功能。

这是既有阶段 3 的纯视觉迭代，用户已经给出风格和范围，直接完成全站视觉及检查，不额外增加选型确认。阅读页保留原有沉浸布局和字号/纸白/护眼/夜间功能，使用一致的纸张与控件质感。

## 开发范围与验收

- 共享导航：桌面为侧栏，窄屏为紧凑顶栏；所有现有入口保留。
- 落地页、创作页、学习记录、登录、个人中心、协议及画廊：统一材质、颜色、间距与阴影。
- 学习记录：原有书籍与顺序、继续阅读、查看全部、状态与进度保持，用实体书及木板承托呈现。
- 阅读、闯关、生成等待、目录和设置：只调整外观，保留对错语义和全部交互。
- 检查桌面 1440 / 1280、平板 768、手机 390；验证原有表单、导航、加载/空/失败状态。
- 运行现有 Lint、类型检查、测试、生产构建，核对受保护的业务文件哈希。
- 真实模型生成不在本次视觉改造范围内，不为截图发起收费生成。需要登录/答题的端到端检查使用数据库副本和真实本地 API；模拟故障须单独标明。
