# 第 3 阶段前端开发文档｜正式网页版

## 1. 本阶段目标
用户在浏览器里（手机+电脑）完成「新建小说 → 逐章生成 → 读正文 → 答 5 题解锁 → 完结 → 结局画廊」，界面正式化。

## 2. 范围
### 本阶段包含
- 页面：首页（书列表+新建书）、阅读页（正文+答题+进度）、结局画廊页
- 组件：Button / Card / 生成进度条 / 答题卡 / 章节正文 / 结局画廊项
- 接口：复用后端 /api 全部接口（books、chapters、tasks、endings）
- 任务状态：submitting / running(带进度) / succeeded / failed
- 产物：文本章节展示

### 本阶段不包含
- 登录/账号、支付、推送、消息（PRD 二期）
- 语音/图片/视频等多媒体产物

## 3. 用户流程
1. 首页：18+ 确认 → 新建书（类型/主题/章节数/篇幅）或打开已有书
2. 点「读下一章」→ 显示生成进度（正在写正文… 已等待 N 秒）
3. 正文展示 → 答 5 题 → 提交 → 通过解锁下一章 / 失败给提示+换题
4. 读完全部计划章或随时「就此完结」→ 大结局 → 结局画廊可重走其他结局

## 4. 页面状态矩阵
| 页面/模块 | 初始 | 加载 | 空 | 运行 | 成功 | 失败 | 恢复 |
|---|---|---|---|---|---|---|---|
| 首页书列表 | 显示列表 | 加载中 | 空提示"还没有书" | - | 列表 | 拉取失败提示重试 | 重新拉取 |
| 新建书表单 | 表单 | 提交中禁用 | - | - | 跳转阅读 | 保留输入+报错 | - |
| 阅读页 | 显示当前章 | 生成中进度 | 无章节提示"读下一章" | 进度文案 | 正文+题 | 生成失败提示重试 | 按 book_id 恢复 |
| 答题 | 题目 | 提交中 | - | - | 解锁提示 | 错题提示+换题 | 重答 |
| 结局画廊 | 列表 | 加载中 | - | - | 已解锁/未解锁 | - | 重新拉取 |

## 5. 接口契约
- 复用后端（见 web.py）：POST /api/books、GET /api/books、POST /api/books/{id}/chapters/next、GET /api/books/{id}/chapters/{no}、POST .../submit、POST .../regenerate、POST /api/books/{id}/finalize、GET/POST .../endings、GET /api/tasks/{id}
- 错误结构：`{"error":{"code","message"}}`，前端统一转 `{code, message, retryable}`，展示 message
- 超时与重试：轮询间隔 1.5s，错误即停；生成中禁止重复提交

## 6. 实现方案
- 路由：`/`（首页）、`/book/[id]`（阅读页）、`/book/[id]/gallery`（画廊）
- 组件结构：features/book、features/chapter、components/ui、lib/api
- 状态来源：后端（book/progress/chapter/task）；临时输入用组件 State
- 流式/轮询：轮询 + 进度文案
- 响应式：390/768/1280；手机单列、桌面居中卡片
- 安全：前端不存 Key；仅通过后端 /api 访问

## 7. 验收标准
- 自动检查：npm run lint / typecheck / test / build 全过
- 真实联调：从首页新建书到解锁下一章的完整闭环走通（接真实后端）
- 响应式：390px 与 1280px 截图
- 刷新恢复：生成中刷新后按书 ID 仍能回到阅读页

## 8. 风险与回退
- 风险：后端生成 90s，用户等待；降级：清晰进度文案 + 已等待计时
- 回退：保留 backend/static 最小 HTML 作兜底入口（8787）
