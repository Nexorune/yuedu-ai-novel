# 阅读 + 闯关代表页验收说明（2026-10-01）

## 背景

产品经理反馈上一版改版"变化不大、交互没优化、视觉不如之前舒服"，并定了三件事：

- **视觉：** 回到改版前的样子。
- **交互：** 四块都要改——答题像闯关、读完看得到收获、阅读更舒服、等待不再干等。
- **参照：** 阅读参照微信读书，答题参照多邻国。

按前端手册的流程，这次先只做"阅读 + 闯关"这一个代表页给产品经理试用，认可后再推到全站。首页和结局画廊已经恢复成改版前的样子。

## 这一页改了什么

| 方面 | 之前 | 现在 |
| --- | --- | --- |
| 答题 | 5 道题全部堆在正文下面，选完一起交卷，交卷后才知道结果 | 章末有"第 N 关"入口，点开进入全屏闯关：一题一屏，选好后点"确认"，马上揭晓对错；答错显示正确答案和讲解（为什么选这个），还能一键"回看原文"；顶部进度条用颜色标出每题对错；5 题答完给出得分和"闯关成功 / 还差一点" |
| 防作弊 | 浏览器拿得到答案；没过关可以改几个选项再交 | 正确答案只在答完那一题后才揭晓；同一题只认第一次作答；一套题答完没过关，必须换一套新题才能再闯 |
| 刷新与中断 | 选到一半刷新，选项全部丢失 | 每题作答都记在服务器上，退出或刷新后能接着答 |
| 读完的收获 | 知识点藏在后台，用户看不到 | 通关后给出"本章收获"，3 张知识卡片（1 个核心 + 2 个拓展）；回看已通关的章节也能看到 |
| 阅读 | 正文混着"第1段"字样，没有设置项 | 像微信读书一样干净：段落号隐藏；往下读时顶栏自动收起；字号 4 档；背景有纸白、护眼、夜间三种；记住读到哪一段，下次打开直接回到那里（会提示"已回到上次读到的位置"，可选"从头读"）；目录抽屉可以跳章 |
| 等待生成 | 一行"正在生成"加秒数 | 步骤条显示走到哪一步（写正文 → 安全审核 → 出题 → 前后文检查 → 完成）；同时给出可看的内容：上回说到（上一章结尾）、复习卡片（已学知识点，可以换一张）、故事简介、登场人物。只展示已读部分，不剧透 |
| 题目质量 | 模型总把正确答案放在 A 或 B，闭眼选同一个字母常能过关 | 出题后由代码打乱选项顺序；还没闯关的旧章节也已打乱（每题正确选项的内容不变），打乱前已整库备份 |
| 讲解 | 无 | 新出的题每道都带一句讲解（已用真模型验证：5 题全部带讲解、不提剧情，花费约 0.02 元）；旧题没有讲解时，显示这道题考的知识点 |

## 照着点（自己验证）

1. 打开 http://127.0.0.1:3002 ，在书架里点《检索官与遗忘图书馆》。
2. **阅读：**
   - 往下滑，顶栏会收起，往上滑又出现；
   - 点右上角"Aa"，试试调字号，背景换成"夜间""护眼"；
   - 点右上角"目录"，看章节列表。
3. **闯关：**
   - 滑到章末，点"开始闯关"；
   - 选一个答案 → 点"确认"，看反馈；答错时可以点"回看原文"，正文里相关的段落会高亮，再点底部的"回到闯关"回来；
   - 注意：这一步是真实答题，会记入这本书的进度。答对 3 题就会解锁下一章。
4. **记住位置：** 读到一半关掉页面，再打开这本书，会回到刚才那一段。
5. **等待生成：** 想看等待页的话，可以打开一本"还没开始第一章"的书（如《倒计时资本玩家》），点"开始第一章"。注意这会真实生成一章，大约 1–2 分钟，产生少量模型费用。
6. **手机：** 电脑浏览器按 F12 → 点手机图标 → 选 iPhone，再走一遍。
