# 账号菜单、封面与滚动验收

## 本次体验

打开 http://127.0.0.1:3012/library 并刷新。

1. 桌面侧栏「新建学习」在上、「学习书架」在下。账号仍在侧栏底部，悬停展开打码手机号、个人中心与退出登录；点击也可开关，Escape 或点击外部可关闭。手机使用顶栏头像入口。
2. 书架有六组配色与山景、沙漏、河流、植物、城市、星轨插画，保留真实书名和进度。
3. 向下滚动可以看到已读书籍和页脚；展开全部仍能滚动。账号菜单不超出窗口。
4. 点 Logo 回到独立落地页；登录状态保留，点「进入学习书架」可以回来。
5. 新建页已删除「开始一本新书」，保留「开始一段新的学习」标题和全部表单设置。

## 核验记录

Tabbit 使用现有真实账号只读核对 17 本书及进度。1357×787、1100×600、900×450、390×844、320×640 五组窗口：账号可见、展开面板完整位于视口内、文档无横向溢出，真实滚轮可到页脚。展开书架后也检查了侧栏区域的滚轮。新建页可滚动至开始生成，未触发生成任务。Logo 与落地页往返检查通过。

账号菜单鼠标悬停、关闭、个人中心入口经过浏览器检查；点击、方向下键、Escape、外部点击、退出失败和恢复按钮有自动化覆盖。退出成功用临时页面拦截 `/api/auth/logout` 和退出后的 `/api/auth/me` 响应验证回到访客首页；这是明确的接口 fixture，并未注销当前真实账号，也不冒充后端真实注销测试。实际组件使用既有的真实注销接口，无后端修改。
