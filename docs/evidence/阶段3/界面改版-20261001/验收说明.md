# 界面改版验收说明（2026-10-01）

> **已撤回（同日）：** 产品经理反馈这版"变化不大、交互没优化、视觉不如之前舒服"。视觉已恢复为改版前；交互改为先做阅读 + 闯关代表页，见 `docs/evidence/阶段3/阅读闯关代表页-20261001/`。本文件仅作记录。

## 这次改了什么

整体还是"中性阅读风"：暖白纸底、近黑正文、松绿按钮。在这个基础上，新增了三个视觉识别点：
- **朱砂印章 Logo**：一个"悦"字印章，网页小图标也换成了它。
- **线装书封面**：每本书都有固定的封面颜色。书名竖排印在题签上，右侧是装订线，左下角盖着小说类型的小印章。
- **宋体排版**：标题和正文都用宋体。

| 页面 | 改版前的问题 | 改版后 |
| --- | --- | --- |
| 年龄确认 | 只有一张卡片 | 卡片两侧各露出一本书；用三个步骤说明怎么玩：写下主题 → 读专属故事 → 答题解锁 |
| 首页 | 像一个宣传页：顶部大插画，书架封面全是色块，书名还重复写了两遍，新建表单藏在页面最底部 | 顶部是问候语，下面是"继续阅读"卡片（自动打开上次读的书）和"想学点新东西？"入口。书架用线装书封面，可以按"全部 / 连载中 / 已完结"筛选。新建表单分三步，左边封面会随你的输入实时变化；每章字数收进了"点此调整" |
| 阅读页 | 正文里夹着"第1段"字样；答题通过后提示马上消失；"读下一章"按钮在侧边栏，手机上要翻到页面最底下才找得到 | 正文排版更好读，段落号移到页边。电脑上左侧有目录，可以直接跳到任意一章。右上角可以调字号（小 / 标准 / 大 / 特大）。答题区改成"闯关测验"：显示答题进度，选项可整块点选。答错时显示得分和"回看第 N 段"按钮，点一下就跳回原文并高亮那一段。通关后出现通关面板，"读下一章"就在面板上 |
| 生成中 | 一行文字提示 | 一张带动画的进度卡片。顶栏一直显示"正在生成 · N 秒"，点它会滚动回进度卡片 |
| 出错时 | 提示显示在页面顶部，用户往下翻了就看不到 | 屏幕底部弹出提示条，可以手动关闭 |
| 花钱的操作 | "就此完结"和"重走结局"点一下就直接执行 | 先弹出确认框，说明会产生费用，确认后才执行 |
| 结局画廊 | 四张普通卡片 | 改成收集卡样式：显示"已收集 1 / 4"，已收集的卡片是金色，未收集的是虚线框 |

业务逻辑没有改动：生成、轮询、断线恢复、提前生成下一章、换题、完结，以及后端接口和数据都和改版前一样。

## 照着点（自己验证）

1. 浏览器打开 http://127.0.0.1:3002 。如果打不开，在 Claude 里说"打开项目"。
2. **首页**：看到问候语和"继续阅读"卡片。点书架上方的"连载中 / 已完结"，书架会跟着筛选。往下翻到"开一本新书"，在主题框里输入"复利"，左边的封面会立刻变成"复利"。不用点"创建"。
3. 点书架里的**《检索官与遗忘图书馆》**：
   - 电脑上左侧有目录（第 1–3 章），点"第 1 章"会跳过去；
   - 点右上角的"Aa 标准"，正文字号会变大，再点就继续切换；
   - 往下翻到"闯关测验"，看到大块的选项和"已答 0/5"。
4. 点任意一本书 → 右上角的"结局画廊"图标 → 看到收集进度和四张结局卡片。
5. 手机上看效果：电脑浏览器按 F12 → 点手机图标 → 选 iPhone，按上面的步骤再走一遍。

注意：只要打开一本"还没答题、而且后面还有章节"的书，并翻到测验区，系统就会照常在后台提前生成下一章，这会产生模型费用。这一点和改版前一样。

## 顺带发现的问题（以下三条已于同日修复，见 `docs/evidence/阶段3/接口加固-20261001/`）

1. **正确答案会发给浏览器。** 章节接口把每道题的正确答案一起返回了，懂一点技术的人在浏览器里就能看到。现在是自己本地用，问题不大；正式上线前必须改成只在后端判分。
2. **书籍详情接口带着"隐藏结局"字段。** 等于提前剧透了结局方向。同样建议上线前去掉。
3. **答错后的提示文案和实际不一致。** 第一次答错时，提示写"已换一套新题"，但实际上要点"换一套题重答"才会换题。文案来自后端，这次没改。
