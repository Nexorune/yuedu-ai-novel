# 测试登录与适配验收（2026-10-22）

## 可以这样体验

1. 打开 http://127.0.0.1:3012/login ，输入自己的手机号，勾选用户协议和隐私政策。现在只有这一个勾选框，没有年龄限制。
2. 刷新后手机号与协议选项仍在；点击手机号，演示验证码自动填写，点「登录」进入学习。首次仍需输入一次，旧页面从未保存的输入无法凭空恢复。
3. 需要换人测试时点「清除记录」。更换手机号也会取消原来的协议勾选。
4. 打开 http://127.0.0.1:3012/ ，缩窄窗口并向下滚动，检查书页和答题卡边界，内容完整可读、不出现横向滚动。长页面仍正常纵向滚动。

## 实际检查

- 登录浏览器实测：重新加载保留手机号和协议，验证码不保存；点击手机号重新填写验证码；只剩一个勾选框。存储键仅 phone、agreed。
- 使用 localhost 的独立存储空间测试，结束后恢复原记录；没有通过浏览器提交测试登录或创建测试用户。
- 后端隔离数据库测试：不传年龄字段可登录；旧客户端传 false 也可登录；未同意协议仍拒绝。默认关闭自动填码，过期自动请求拒绝；账号隔离检查保留。
- 访客首页在 320、375、390、456、480、600、768、800、820、1024、1280、1440px 的页面宽度等于窗口宽度，书页与浮卡在容器内；456px 当前内置浏览器截图确认。
- 登录布局使用独立接口 fixture 检查 320、390、768、1024、1440px，无横向溢出；fixture 只用于导航布局，不冒充真实账号验证。
- 前端 22/22、后端 72/72，Lint、类型检查和 Webpack 生产构建通过。后端既有 Starlette/httpx 弃用提示不影响测试通过。
