# 错题本按书整理

## 打开与体验

1. 打开 http://127.0.0.1:3012/mistakes，默认看到有待巩固错题的书本目录，每本显示封面、书名、待巩固/已掌握数量和章节数。
2. 点一本书进入该书错题，按章节分组；题目默认收起，点开后可见当时的选择、正确答案、讲解、原文摘录和掌握状态操作。
3. 题目每页最多 20 道，书本目录每页 12 本；可按掌握状态、章节和关键词缩小范围，切换筛选会回到第一页。
4. 点击「回到书中知识」定位对应章节知识，返回入口回到该书错题本。书本地址可刷新，浏览器前后退不会留下另一页的章节筛选。

浏览器通过：书本隔离、20/5 分页、章节筛选、展开详情、掌握/移回及刷新保存、原文回看与返回相应书本、页面刷新和浏览器前后退。书本目录与题目页在 1440/768/390/320 宽度无横向溢出。前端 41/41、类型、Lint、Webpack 生产构建全部通过。单元测试另覆盖 13 本书的 12/1 分页和筛选复位。

本次分页控制页面呈现数量；后端仍使用现有接口一次返回当前用户错题，未将前端分页描述成服务端分页。数据量进一步增长时可再加后端按书聚合与分页接口。
