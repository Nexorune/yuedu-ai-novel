# 演示版登录 · 验收说明（2026-10-18）

## 照着点
1. 浏览器打开 http://127.0.0.1:3012/ ：看到落地页（首屏、三步说明、示例、常见问题），右上角是「登录」，页面上没有任何输入框。
2. 点「开始学习」→ 跳到登录页。
3. **用你自己的手机号**登录（第一个登录的账号会接手现有 17 本演示书）：填手机号 → 点「获取验证码」→ 填演示码 → 勾选两项 → 登录。
4. 进入创作页，学习记录里能看到 17 本书；右上角变成头像。
5. 点头像进入个人中心，能看到读过 17 本书、通关章节、学会的知识点；点「退出登录」回到落地页。
6. 换一个手机号登录，学习记录是空的——说明每个人只能看到自己的书。
