# 章节知识清单验收

## 怎么体验

1. 打开 http://127.0.0.1:3012/library，选择已有小说，进入任一可读章节。
2. 正文后、闯关区之前是「本章知识点」。不必先通关即可查看，核心知识排在前面，拓展知识紧随其后，保留完整说明。
3. 阅读页顶部灯泡按钮「查看知识点」可快速跳到清单。
4. 切换「本书知识目录」，按章节展开知识；可搜索知识点或章节名，搜索时自动展开匹配章节。点击「阅读这一章」回到对应章节。
5. 尚未解锁的后续内容不会提前出现；随阅读进度推进加入目录。空知识章节有明确提示。
