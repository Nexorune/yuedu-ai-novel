# 阶段 3 体验修订验收记录（2026-09-30 收尾版）

## 可自行核对

1. 打开 http://127.0.0.1:3002 ，进入书架。书封显示独立书名（如《复利囚徒》），副文案显示学习主题；原两本「性知识」书不在书架上（数据保留未删）。
2. 打开有章节的书（如《复利囚徒》#19），看正文与测验：5 道题考的是学习主题知识（复利定义/公式计算/复利vs单利），不再考人物、绰号、剧情。
3. 对有后续章节的书，滚动到测验区会自动启动下一章后台生成；答题未通过前直接请求下一章返回 403。
