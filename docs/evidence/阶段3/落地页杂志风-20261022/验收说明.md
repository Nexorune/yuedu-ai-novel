# 首页杂志风 · 2026-10-22

## 看效果

打开 http://127.0.0.1:3012/ 。原来停留在 /login 的浏览器请进入此首页地址。

1. 未登录时应看到顶部悦读标志与登录入口，页面全宽，没有左侧工作区导航。
2. 首屏为米白自然光背景、宋体标题、陶土橙按钮和书页/答题浮卡。向下滚动查看河畔阅读示例、三步说明、四个常见问题及深色页脚。
3. 点击任一「开始学习」，未登录时进入 `/login?next=%2Fcreate`。浏览器返回后首页正常显示。
4. 点击每个常见问题可展开答案，再点可收起；键盘 Tab 聚焦后按 Enter 同样可操作。
5. 手机窄屏时阅读示例和题目上下排列，三步说明改成纵向；页面不横向滚动。
