# 阶段 3 证据包｜正式前端

## 你可以打开的预览

- 当前生产构建预览：http://127.0.0.1:3003
- 后端旧版兜底：http://127.0.0.1:8787

照着点：
1. 打开 3003 地址，点「我已年满 18 岁，进入悦读」。
2. 首页向下看「我的书架」，书籍来自真实后端；再看「新建一本小说」表单。
3. 点书架上的「蝴蝶效应」，可阅读已生成章节并看到 5 道题。
4. 返回书架，点已完结的 AI 主题书，再点「结局画廊」，可看到 4 种结局状态。原验收所用的两本“性知识”书已在后续体验修订中从书架隐藏。
5. 生成按钮会调用模型并产生用量费用；阶段验收已用快速短篇完成一次真实闭环。
