# 知识侧栏验收

## 怎么体验

1. 打开 http://127.0.0.1:3012/library，进入任一已有小说章节。
2. 点击阅读顶部带灯泡的「知识点」，左侧直接打开本章清单。也可点击「目录」，在侧栏顶部切换「章节目录 / 知识点」。
3. 在知识视图切换「本书知识目录」，搜索知识或章节；展开后点击「阅读这一章」，侧栏收起并返回对应章节。
4. 关闭按钮、Esc 或点击外侧遮罩返回阅读；阅读位置保留。正文底部已移除原知识区，章末直接接闯关区。
5. 手机上侧栏内容可单独上下滚动，关闭按钮和两个视图入口始终在上方；支持现有阅读主题。
