# 我的错题本验收

## 打开与体验

1. 打开 http://127.0.0.1:3012/mistakes，登录后可看到「学习书架」下方新增的「我的错题本」。
2. 默认查看「待巩固」，可以按书筛选、搜索题目或知识点。
3. 展开「查看答案与讲解」可看到正确答案、解析和保存的书中摘录。
4. 点击「回到书中知识」，进入相应书籍章节并高亮对应段落。顶栏「错题本」可返回；链接刷新后仍可定位。
5. 学会后点击「标为已掌握」，切换「已掌握」可查看或移回待巩固，不删除记录。
6. 每次闯关答错即自动收录，即使最终通关也保留错题。换题不会删除已收录题目。

## 实现边界与历史记录

按书籍所属账号隔离，只有本人能查看、改变分类。错题存入 SQLite，保存题干、选项、当时错误选择、正确答案、解析、知识点、书/章节和原文摘录。相同书/章内的完全相同题目及来源去重，避免重复请求重复收录；不统计作答次数。已掌握是用户手动标记，不冒充再次测验结果。

原库迁移前已 SQLite 在线备份：backend/data/novel_learning.db.bak-before-mistakes-20261022-113539。原书籍、章节、账号、进度与当前作答数量不变；从保留的 1 组作答中补收录 5 道错题。旧代码曾在换题时清除作答，因此已被清除的历史无法恢复。

原文定位优先匹配保存时的段落文本，不在正文变化后盲用旧段号；匹配不到时提示查看已保存摘录。无分段标记的旧正文定位到全文。回顾模式不改变正常阅读位置，不自动预生成下一章；用户主动点击原有生成操作仍沿用原规则。
