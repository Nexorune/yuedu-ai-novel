# 样例 3：悬疑 × 蝴蝶效应

第1段
深夜十一点，理论物理系大楼三层东侧的实验室灯火通明，与窗外沉寂的校园形成鲜明对比。林深揉了揉酸涩的眼睛，视线从屏幕上密密麻麻的微分方程移开，落在桌角那份只啃了两口的三明治上。胃在抗议，但大脑还在为毕业论文模型的收敛性问题高速运转。这个关于混沌系统中微小扰动传播路径的模拟，已经卡了他整整一周。他总是下意识地追求模型的确定性和可预测性，哪怕研究对象本身就是“不确定性”的代名词。这或许源于内心深处某个无法愈合的伤疤——那个名叫小雨的童年好友，她的离去就像生命系统中一个无法预测也无法逆转的突变。

第2段
就在他准备重启一次计算时，门外传来轻微的窸窣声，随即是物体被放在地上的闷响。林深皱了皱眉，这个时间点，清洁工早已下班。他起身走到门边，透过门上的玻璃窗向外望去，走廊空无一人，只有节能灯管发出苍白的光。打开门，一个约A4纸大小的牛皮纸包裹安静地躺在门口，没有快递单，没有任何标识，只用黑色马克笔写着“林深 亲启”，字迹工整却透着一种刻意的陌生感。

第3段
林深的第一反应是警惕。他最近没有网购，更不会有人把东西直接送到深夜的实验室。理性告诉他应该置之不理，或者明天交给物业处理。但另一种莫名的直觉，或者说是一种被理性压抑已久的好奇，驱使他弯腰捡起了包裹。很轻，里面似乎是本书或硬皮笔记本。他拿着包裹回到实验台前，犹豫片刻，用裁纸刀小心地划开了封口胶带。

第4段
里面果然是一本黑色硬壳笔记本，封面没有任何文字。翻开扉页，林深的呼吸微微一滞。扉页中央，用铅笔淡淡勾勒着一只蝴蝶的图案。但这只蝴蝶并非完整，它的一边翅膀呈现出不规则的破碎状，线条精细得仿佛能感受到翅膀碎裂时的张力。图案下方，靠近装订线的地方，有一个极小的、需要凑近才能看清的钢印痕迹：“CSM-Lab-07”。CSM？这三个字母的组合让他心头一跳。他的导师陈正明教授名字的拼音首字母，正是CZM，虽然差了一个字母，但“CSM”这个缩写……在系里，私下里学生们有时会用“陈氏模型”来指代陈教授那套影响力颇大的理论框架，其缩写也恰好是CSM。至于“Lab-07”，物理系大楼里以“07”编号的实验室有好几间，用途各异。

第5段
笔记本的纸张是普通的横线内页，但从第一页开始，就写满了字。字迹工整，用的是蓝色墨水，笔触稳定，像是用某种特定型号的钢笔书写。开篇没有标题，直接就是一段令人脊背发凉的文字：“未来三天，本市将发生一起‘完美犯罪’。它将被精心设计，湮灭于无数偶然与必然交织的混沌之中，无人察觉其人为痕迹，直至结果发生。”

第6段
林深感觉喉咙发干。他快速翻动了几页，内容并非连续的小说或臆想，而像是一份……观察记录？或者说，预测清单？条目清晰，时间、地点、涉及人物（大多用代号或特征描述）、关键细节，甚至包括一些环境参数的微小异常。其中一条，用红笔做了重点标记，吸引了林深全部的注意力：“明晚20:45至21:15，云顶酒店顶层露天花园酒会，西侧弧形观景露台，自北向南数第三段栏杆。关键：该段栏杆内侧下方，距地面1.2米处，存在一处长约5厘米、深约2毫米的隐蔽性结构性裂纹。裂纹于本周一（4月15日）由酒店工程部内部巡检发现，记录于维修报告‘WL-0423’号，评估为‘低风险，计划于下月初维修’，报告未公开，仅限工程部及酒店管理层极少数人知悉。”

第7段
云顶酒店？顶层露天花园酒会？林深的指尖有些发凉。他的导师陈正明教授，为了给那个至关重要的跨学科科研项目争取支持，明天晚上正是在云顶酒店顶层举办一场学术晚宴，邀请了不少学界和投资界的重要人物。时间、地点完全吻合。林深作为陈教授的学生，虽然没有被邀请参加（这种场合显然不属于他这种“社恐”兼“劳动力”），但他昨天帮陈教授核对过晚宴的流程安排和场地确认邮件，对此一清二楚。

第8段
“裂纹……”林深低声自语。笔记本的描述精确到了厘米和毫米，连内部报告编号都写了出来。如果是恶作剧，需要如此大费周章地调查酒店不公开的工程细节吗？他感到一阵眩晕，仿佛脚下坚实的地面正在变成流沙。他研究的是混沌理论，天天与“蝴蝶效应”打交道——初始条件的微小差异，经过系统内非线性过程的放大，最终可能导致截然不同的结果。一只蝴蝶扇动翅膀，可能引发一场风暴。那么，一处不为人知的微小裂纹，在特定的人群聚集、特定的时间、特定的受力条件下，会不会引发一场“意外”？这个念头让他不寒而栗。

第9段
他强迫自己冷静下来，尝试用学术思维分析。混沌系统对初始条件具有极端敏感性，这是基本原理。但现实中的事件，尤其涉及到人为活动的复杂系统，变量多到无法穷尽，任何预测都近乎不可能。这本笔记，却宣称能预测一起基于微小物理缺陷（裂纹）可能引发的“犯罪”？如果裂纹是关键初始条件，那么是谁，通过什么方式，去“触发”它，从而导向一个特定的、恶劣的结果？笔记称之为“完美犯罪”，意味着触发方式将极其隐蔽，甚至可能伪装成自然发生的意外。林深的目光再次落到那只破碎翅膀的蝴蝶图案上，感觉它仿佛在无声地扇动着不祥的预兆。

第10段
就在这时，他发现在笔记本第一页那段关于“完美犯罪”的宣言下方，还有一行用更细的笔尖写下的小字，之前被忽略了：“用你的蝴蝶效应理论，阻止它，否则下一个就是你。”字迹与正文相同，但墨色似乎稍淡一些，像是一句事后补充的警告。冰冷的威胁感穿透纸张，直抵林深的心脏。“下一个就是你”——这不再是旁观者的警告，而是直接将他拽入了漩涡中心。

第11段
他猛地合上笔记本，仿佛它会烫手。是谁？谁寄来的？知道他研究蝴蝶效应，知道他导师的行程，甚至可能知道他内心深处对“确定性”和“挽回”的执念？小雨的面容在脑海中一闪而过，带来一阵尖锐的刺痛。不，不可能。那只是他隐秘的伤疤。他将笔记本塞回牛皮纸袋，手指无意中触碰到袋底，似乎还有东西。拿出来一看，是一张对折的便签纸，上面打印着一行字：“验证机会：明早九点前，云顶酒店工程部值班人员换班间隙，内部系统可短暂外部访问（漏洞窗口约3分钟）。报告‘WL-0423’。”

第12段
这简直是一份“邀请函”，或者说，一个测试。对方不仅给出了预测，还提供了验证预测真实性的途径。去验证，就意味着他要主动介入，去触碰一个未知的领域，甚至可能涉及不道德的“黑客”行为。不去验证，这根刺将永远扎在心里，尤其是那句“否则下一个就是你”。林深感到自己正站在一个岔路口，理性告诉他这很可能是一个精心设计的陷阱或恶作剧，应立即报警或将东西交给导师陈正明处理。但另一种声音，一种混合了科学好奇心、对潜在威胁的恐惧，以及某种连他自己都不愿深究的、想要“做点什么”来对抗命运无常的冲动，在拉扯着他。

第13段
导师陈正明的形象浮现在眼前。儒雅，睿智，总是带着鼓励的微笑，但林深能感觉到那笑容背后精确的计算和掌控。陈教授会怎么看待这件事？会认为是学生的妄想，还是敏锐地察觉到其中的蹊跷？以陈教授处事周密的风格和正在为晚宴全力筹备的状态，大概率会先安抚他，然后谨慎地调查，但最终可能为了晚宴的万无一失而采取一些林深无从知晓的措施。但那样，林深自己就彻底变成了被动的告知者，失去了对事态的任何掌控，也无从得知笔记本和警告的真相。

第14段
林深看了一眼电脑屏幕，他的混沌模型还在等待运算。现实世界的“混沌”，似乎以一种更直接、更危险的方式找上了门。他重新打开笔记本，翻到关于云顶酒店裂纹的那一页，用手机拍下了照片，包括那个“CSM-Lab-07”的钢印。然后将笔记本和便签纸小心地放回牛皮纸袋，藏进了自己书包的夹层。他决定暂时不告诉任何人。至少，在明天早上九点之前，他要做出自己的判断。是置之不理，赌一切都是虚惊一场？还是按照便签的提示，冒险去验证那个“裂纹”是否存在？

第15段
窗外的夜色更浓了。实验室里只有机器运转的低鸣和日光灯管的电流声。林深关掉了电脑上复杂的模型界面，打开了一个普通的网页浏览器。他的手指在键盘上悬停片刻，最终在搜索栏键入了“云顶酒店 结构安全 近期检修”。网页上只有官方通用的宣传信息和一些客人的评价，毫无异常。这很正常。如果笔记本所言非虚，这种信息绝不会公开。他靠在椅背上，闭上眼睛，感觉太阳穴在突突跳动。蝴蝶的翅膀已经开始扇动，而他，正站在风暴即将形成的位置。他不知道的是，在他实验室楼下阴影里，一个模糊的身影抬头望了一眼他窗口的灯光，随即无声地融入夜色，只留下地上一小片被碾碎的落叶，叶脉的纹路，在远处路灯光下，依稀有点像蝴蝶翅膀的纹理。
