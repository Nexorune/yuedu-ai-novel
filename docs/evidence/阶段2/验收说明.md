# 阶段 2 证据包｜后端 MVP（网页版）

## 一、你能自己打开的地址

```
http://127.0.0.1:8787
```

（服务已在运行。若打不开，让 AI 执行启动命令即可。）

## 二、照着点（验收步骤）

1. 浏览器打开 `http://127.0.0.1:8787`
2. 勾选「我已年满 18 岁」→ 点「进入」
3. 在「新建一本小说」里：选类型（如 爽文）→ 填主题（如 复利）→ 点「创建并开始」
4. 等生成（约 30 秒–2 分钟，按钮会转圈并提示"生成中"）
5. 读正文 → 答 5 道题（选 A/B/C/D）→ 点「提交答案」
6. 答对 ≥3 题 → 解锁下一章；答错 → 看提示、可「换一套题重答」
7. 随时可点「就此完结」→ 生成大结局 → 「结局画廊」可重走其他结局
