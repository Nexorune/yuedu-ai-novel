# 悦读正式前端

Next.js App Router + TypeScript + Tailwind CSS。复用现有 FastAPI 服务，不在浏览器中保存模型密钥。

## 本地预览

先确认后端在 http://127.0.0.1:8787 运行。在 frontend 目录执行：

    npm install
    npm run dev -- --hostname 127.0.0.1 --port 3012

浏览器打开 http://127.0.0.1:3012 。3000、3002 端口目前被本机其他项目占用，所以悦读预览使用 3012。

生产构建预览可执行：

    npm run build
    npm run start -- --hostname 127.0.0.1 --port 3003

浏览器打开 http://127.0.0.1:3003 。

所有 /api/* 请求由 Next.js 代理到后端。默认目标是 http://127.0.0.1:8787 ；如需更改，在构建或启动开发服务器前设置服务端环境变量 BACKEND_URL。模型 Key 只留在后端 .env。

## 页面与登录（2026-10-18 演示版）

- `/` 落地页：只展示，不可操作；按钮未登录去 `/login`，已登录去 `/create`。
- `/login` 手机号 + 验证码登录（新号自动注册）。演示版不发真实短信，验证码为后端 `DEMO_LOGIN_CODE`（在 backend/.env 设置，未设置时用 config.py 默认值）。
- `/create` 创作页 + 学习记录；`/book/{id}` 阅读与闯关；`/book/{id}/gallery` 结局画廊；`/me` 个人中心；`/terms`、`/privacy` 协议页。
- 登录状态存在 HttpOnly Cookie（30 天）；后端统一中间件拦截未登录请求（401 时前端自动带到登录页），别人的书一律返回 404。
- 第一个登录的账号会接手接入账号前的全部书籍（演示数据）。共用组件：components/site/SiteHeader.tsx（桌面侧栏 / 手机顶栏与页脚）、lib/account.ts（登录状态）。

页面：/ 落地页、/create 创作与学习记录、/book/[id] 阅读与答题、/book/[id]/gallery 结局画廊。

阅读页（2026-10-01 交互改版，2026-10-21 更新为书房视觉）：组件在 components/reader/——QuizMode（多邻国式逐题闯关，调用 /answer 逐题判分）、KnowledgeCards（本章收获）、WaitingPanel（生成等待：步骤条 + 上回说到/复习卡片/登场人物，调用 /recap）、ReaderSheets（目录抽屉与阅读设置）、useDialog（弹层焦点与 Esc）。正文拆段、知识卡片标题、回看原文定位在 lib/chapter.ts；字号、背景（纸白/护眼/夜间）、读到哪一段等本机偏好在 lib/prefs.ts（只存浏览器本地，读写失败退回默认值）。夜间背景由 app/layout.tsx 里的内联脚本在绘制前设置，避免闪白。首页与结局画廊已统一为书房视觉。改版前代码备份在项目根目录 备份/前端改版前-20261001/。新书会在生成大纲时得到书名。滚到章末闯关入口时，如果还有下一章，会自动启动一次后台提前生成；即使只查看章节，也可能产生该次模型费用。通关后点「读下一章」，已生成的章节可直接打开。
