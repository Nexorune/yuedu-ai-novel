# 悦读 · 边追更，边学东西

通过小说学习知识：选择学习主题与故事类型，生成个性化故事，每章完成测验后解锁后续内容。

## 当前版本

- 首页介绍、独立创作页与学习记录。
- 手机号演示登录、个人中心、按账号隔离数据。
- 阅读目录、字号与纸白/护眼/夜间主题。
- 逐题闯关、错题讲解、进度恢复、知识卡片与结局画廊。
- 2026-10-21 书房视觉：奶油色内页、实体书封、木质书架及移动端适配。
- 2026-10-22 首页杂志风：米白纸感、陶土橙、叠放书页与答题浮卡；访客全宽落地页，登录后保留书房导航。

前端为 Next.js / React / TypeScript，后端为 FastAPI，SQLite 保存书籍、任务和学习进度。模型经服务端配置调用。

## 本地启动

需要 Python 3.12 和 Node.js 22 或更高版本。分别在两个终端启动后端、前端。

### 后端

```sh
cd backend
python3.12 -m venv .venv
./.venv/bin/pip install -r requirements.txt
cp .env.example .env
```

编辑 `backend/.env`，填写自己的模型服务配置，并将演示登录码设为六位数字。配置文件被 Git 忽略；不要提交真实密钥。

```sh
./.venv/bin/python -m uvicorn novel_learning.web:app --host 127.0.0.1 --port 8787
```

### 本机测试登录

在已忽略的 `backend/.env` 中设置 `DEMO_LOGIN_AUTOFILL=true`，重启后端后启用测试便利功能。手机号及已经勾选的选项保存在当前浏览器；返回登录页会恢复，点击完整手机号后自动向本机后端获取并填入演示验证码。首次仍需输入手机号、勾选确认；「清除记录」可删除保存的信息。验证码不持久化。登录只需勾选用户协议和隐私政策，不要求成年确认。换浏览器或将 `127.0.0.1` 换成 `localhost` 属于不同存储空间。

示例配置默认关闭此开关。公开部署前必须设为 `false`，并按 PRD 接入真实短信验证；仅关闭自动填写不等于已完成正式登录系统。

### 前端

在另一个终端中，从项目根目录执行：

```sh
cd frontend
npm ci
npm run dev -- --hostname 127.0.0.1 --port 3012
```

打开 http://127.0.0.1:3012 。前端默认代理 API 到本机 8787 端口；如需修改，设置服务端环境变量 `BACKEND_URL`。完整前端说明见 [frontend/README.md](frontend/README.md)。

## 验证

```sh
cd backend
./.venv/bin/python -m pytest tests/
```

```sh
cd frontend
npm run lint
npm run typecheck
npm run test
npm run build
```

如本机 Turbopack 遇到临时端口权限问题，可用 `npm run build -- --webpack`。2026-10-22 已通过前端 22 项测试、Lint、类型检查和 Webpack 生产构建；本轮视觉验收未调用真实模型。

首页验收：打开 `/`，检查首屏、阅读示例和手机布局，展开四个常见问题；未登录点击「开始学习」应进入 `/login?next=%2Fcreate`。本轮检查记录见 [首页杂志风验收](docs/evidence/阶段3/落地页杂志风-20261022/验收说明.md)，图片来源及生成提示词见 [本轮开发文档](docs/阶段文档/落地页杂志风-20261022.md)。

## 数据与演示边界

本仓库不包含 `.env`、用户数据库、运行日志、本地备份和验收原始截图。首次启动创建新的数据库，已有本机书籍与账号不会随代码上传。生成故事、换题和重走结局会产生模型用量；阅读连载到章末也可能提前生成下一章。

当前为本地演示版：验证码固定、不发送短信，正式公开上线前需要完成 PRD 中的上线前补齐项。GitHub 上传不等于网站部署。
